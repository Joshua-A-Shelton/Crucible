# 0005 — 2D

**Status:** Accepted (2026-10-24).

## Context

Goal 6: excellent 2D, secondary to 3D. "2D" covers different kinds of
game:

- **Pixel art** (Celeste, Dead Cells): exact pixel placement, integer
  scaling, no sub-pixel shimmer.
- **HD 2D** (Hollow Knight, Ori): high-resolution sprites with lighting,
  particles, parallax.
- **Mixed / 2.5D** (Octopath Traveler's HD-2D, Paper Mario): sprites in 3D
  worlds, or 3D elements in 2D games.

How engines do it: Godot has a separate 2D renderer (excellent 2D, awkward
mixing); Unity runs 2D on the 3D renderer (easy mixing, 3D's overhead);
Unreal's Paper2D shows what happens when 2D is an afterthought.

## Decision

- **Pixel art is the true 2D path.** It gets a dedicated 2D renderer:
  sprite batching, draw-order sorting (layers, order in layer, y-sort), and
  2D lighting, built on the same foundation as 3D (Slag, materials, the
  frame phases of goal 7) and able to composite with 3D in one frame.
- **HD 2D and mixed 2D/3D use the 3D renderer.**
- **Pixel-perfect rendering is first-class:** a virtual-resolution camera,
  integer scaling (with a sharp scaler for non-integer window sizes),
  nearest-neighbor filtering, and pixel snapping.
- **Dedicated 2D physics,** not 3D physics constrained to a plane. The
  library is chosen later (third-party decision).
- **Built in:** tilemaps and frame-based animation. Skeletal 2D animation
  comes later or as a plugin (Spine's runtime license is proprietary, so it
  can't be a default dependency).

## Why

Pixel art has requirements the 3D renderer would fight (integer pixel
grid, no filtering, exact sorting), so it gets its own path. HD 2D and
mixed scenes want what the 3D renderer already does well (lighting,
depth, particles), so a second copy of those features in 2D would be
duplicated work. Pixel-perfect support is hard to retrofit. Dedicated 2D
physics is simpler, faster, and behaves the way 2D games expect.

The clarity goal carries over: pixel art is drawn at its virtual
resolution and scaled up by whole pixels, so MSAA doesn't apply and
nothing is filtered.

Given up: one renderer for every kind of 2D.
